# ⚽ SiaBet – Sports Betting Platform

SiaBet is a modern sports betting web application focused on football, designed to provide users with an intuitive and responsive interface for exploring football matches and sports-related information.

## 🚀 Overview

The project is built with Vue 3 and Vite, focusing on modern frontend development practices, reusable components, and a responsive user interface.

## ✨ Features

- Modern and responsive user interface
- Football-related data integration
- Sports match information
- Dynamic frontend components
- Clean and maintainable code structure
- Optimized development environment

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Vue 3 | Frontend Framework |
| JavaScript | Programming Language |
| Vite | Build Tool |
| HTML5 | Markup |
| CSS3 | Styling |
| Sportmonks API | Football Data Integration |

## 📂 Project Setup

Clone the repository:

```bash
git clone https://github.com/Ali-Reihani/siabet.git
```

Navigate to the project directory:

```bash
cd siabet
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
